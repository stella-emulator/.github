# Stella - Atari 2600 Cartridges

![Stella with a 2600 cartridge and the console switches mapped](https://stella-emu.github.io/title.png)

## At a Glance

Stella boots a 2600 cartridge and exposes the switches real hardware had: color or black-and-white, difficulty, and select or reset. Many games need those switches. A pad mapped only to the stick will feel broken until select and reset exist. Map them.

- Cartridge images you may use
- Joystick, paddles, or keyboard depending on the game
- TV mode and phosphor options after the game runs
- Saves or high scores where the game had them
- A debugger you can ignore

1. Map the stick, fire, Select, and Reset.
2. Load one cartridge.
3. Press Reset if the screen waits.
4. Change TV filters only after play starts.
5. Keep paddle games on a device that can act as a paddle.

## Fits

2600 software you may run. A poor fit for later Atari machines. A poor fit if you expected Stella to supply the cartridges.

## Fixes

The screen sits on garbage. Press Reset, or set the bankswitch type if this dump needs it.
Paddles do not move. You mapped a stick.
Color is wrong. Toggle the color switch.
A 7800 file will not run. It is a different emulator.
Nothing is fun because Select was never bound. Bind it.

## Switches Are the Game

A 2600 title often sits on a screen that looks broken until Select or Reset is pressed, or until the difficulty switches match the manual. Map those before you change phosphor, scanlines, or the TV palette. A pretty window of a game that has not been reset is not a video bug.

Paddle games need a paddle axis. Mapping them to a stick makes the game feel random. Keyboard players should still bind Reset, because many sessions start there and nowhere else.

| Control | Bind it |
|---|---|
| Stick and fire | Almost every cart |
| Select and Reset | Before you judge the picture |
| Paddle axis | Only the games that used paddles |
| Color switch | When the picture is mono or unstable |

Keep one cartridge that already runs as a control. If that one still boots, a new file that will not start is the dump or the bankswitch setting, not a broken Stella install. Saves and high scores, when a game has them, are small files worth copying with the ROM. Stella does not store them inside the cartridge image.

## Reset and Select Before the Filter

A 2600 game often looks broken until Reset is pressed or the difficulty switches match the manual. Map stick, fire, Select, and Reset before you change phosphor or the palette. Paddle games need a paddle axis. A stick makes them feel random. Color versus black-and-white is a real switch, not a shader.

Keep one cartridge that already runs. If it still boots, a new file that will not start is the dump or the bankswitch type. 7800 and Jaguar files are different emulators. Stella does not include the cartridges. High scores, when a game stores them, are small files worth copying with the ROM.

- Console switches bound
- Paddles only on paddle games
- One control cartridge
- Bankswitch set when a dump needs it
- Filters after play starts
- Later Atari machines sent elsewhere
- ROMs only if you may use them

| Screen | Try |
|---|---|
| Garbage at start | Reset |
| No color | The color switch |
| Paddle game unplayable | Paddle axis |
| 7800 file | A different emulator |

The debugger can stay closed. The switches cannot.
